Factory Inventory Management System

Architecture overview: system structure, technology stack and data flow

Summary

A demo full-stack application with a Vue 3 single-page frontend and a FastAPI backend. There is no database: the backend loads JSON files into memory at startup and answers every request by filtering those lists in Python. Four filters (period, warehouse, category, order status) are held in shared client state and sent as query parameters, so every screen reflects the same slice of data.

Data flow

Request path

  1. The user changes a filter in FilterBar (period, warehouse, category, status).
  2. useFilters updates module-level refs shared by every view.
  3. A view watcher fires and calls api.js with getCurrentFilters().
  4. axios sends a GET with query parameters; values of all are omitted.
  5. FastAPI applies apply_filters and filter_by_month to the in-memory lists.
  6. Pydantic validates the result and FastAPI returns JSON.
  7. The view stores raw data in refs and derives charts and totals in computed properties.

Startup path

  1. python main.py starts Uvicorn on port 8001.
  2. Importing mock_data.py reads each file in server/data/.
  3. Lists are held in memory for the life of the process.
  4. Endpoints read the lists directly; nothing is written back.
  5. generate_data.py can regenerate the JSON files offline.

Filter support by endpoint

Quarters (Q1-2025 to Q4-2025) and months (2025-01) are matched as substrings of order_date. Inventory has no date, so it ignores the period filter.

Observations

Client and server are out of step. client/src/api.js calls /tasks (GET, POST, PATCH, DELETE) and /purchase-orders (POST, GET), but server/main.py defines no such routes, so those calls would return 404. The backend has PurchaseOrder models and loads purchase_orders.json, but only uses them to set has_purchase_order on backlog items. Also, views/Backlog.vue has no route registered in main.js.

Design choices

  • All business logic sits in a single backend file.
  • Shared filter state uses module-level refs rather than a store library.
  • Language and currency switch together (en / USD, ja / JPY).

Demo-only limits

  • CORS allows all origins; there is no authentication.
  • Backend URL is hard-coded in the client.
  • Quarter mapping covers 2025 only.
